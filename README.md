# Agent Context Memory Contract

This example demonstrates how an AI agent can lose context without a proper 'memory contract' and how a simple memory mechanism helps maintain conversational coherence over multiple turns, addressing the core problem discussed in the article.

## Language

`python`

## How to Run

Run the Python script from your terminal: python main.py
